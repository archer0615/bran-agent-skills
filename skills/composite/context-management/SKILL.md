# Context Management

## Procedure

Maintain compact task state with objective, constraints, decisions, open questions, evidence, files, and next action. Prefer repository evidence, summarize before context grows, and reconcile conflicts by authority and recency.

## Output

Return the structured artifact, assumptions, unresolved questions, and concrete verification or review criteria. Communicate with the user in Traditional Chinese unless another language is requested.
