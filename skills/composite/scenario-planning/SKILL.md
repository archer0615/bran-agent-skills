# Scenario Planning

## Use when

Use this skill when exploring plausible futures, uncertainty, or decisions that must remain robust across changing conditions.

## Procedure

1. Define the focal question, decision horizon, baseline, scope, and decisions that must remain viable.
2. Identify driving forces, known trends, critical uncertainties, dependencies, and constraints.
3. Select a small set of independent, plausible, and meaningfully different scenarios; include the baseline when useful.
4. Describe each scenario, implications, risks, early signals, and conditions without presenting it as a prediction.
5. Test current options across scenarios and identify robust, contingent, and fragile choices.
6. Recommend no-regret actions, trigger-based actions, monitoring signals, and a review cadence.

## Decision rules

- Scenarios are plausible decision tools, not predictions unless separately supported by probability evidence.
- Keep scenarios distinct and separate evidence, assumptions, uncertainty, and interpretation.
- Prefer no-regret actions under high uncertainty; gate irreversible actions with signposts.

## Verification

- Scenarios are plausible, distinct, internally coherent, and not disguised forecasts.
- Key assumptions, uncertainties, signals, and time horizon are explicit.
- Options are tested consistently across scenarios.
- Actions include triggers, owners where applicable, and a reassessment point.

## Output

Return the focal question, baseline, forces, uncertainties, scenarios, implications, signals, robust options, no-regret actions, assumptions, and review criteria. Communicate with the user in Traditional Chinese unless another language is requested.
