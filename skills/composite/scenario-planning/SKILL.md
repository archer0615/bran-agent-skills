# Scenario Planning

## Procedure

Define focal question, forces, uncertainties, horizon, and baseline. Build distinct scenarios, implications, early signals, options, and no-regret actions. Do not present scenarios as predictions.

## Output

Return the structured artifact, assumptions, unresolved questions, and concrete verification or review criteria. Communicate with the user in Traditional Chinese unless another language is requested.
