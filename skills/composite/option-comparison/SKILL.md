# Option Comparison

## Procedure

Clarify the decision, constraints, and weighted criteria. Build a comparison with evidence, assumptions, costs, risks, trade-offs, and fit. Separate facts from judgment and recommend an option with conditions.

## Output

Return the structured artifact, assumptions, unresolved questions, and concrete verification or review criteria. Communicate with the user in Traditional Chinese unless another language is requested.
