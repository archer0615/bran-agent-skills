# Prompt Evaluation

## Procedure

Define representative inputs, expected behavior, failure cases, and criteria. Test ambiguity, missing data, adversarial wording, and language requirements. Record regressions and revise minimally.

## Output

Return the structured artifact, assumptions, unresolved questions, and concrete verification or review criteria. Communicate with the user in Traditional Chinese unless another language is requested.
